# Nacerddine Rim — Data Engineering & Analytics Portfolio

Personalized from the original stenotype portfolio concept with resume details and public GitHub projects.

## Run it

From the folder containing this README:

```bash
python3 -m http.server 8000
```

Open http://localhost:8000.

## Customize

- Update the email and GitHub URL at the top of `js/main.js`.
- Update the `projects` array in `js/main.js` to add or remove GitHub repositories.
- Main page copy lives in `index.html`.
- Visual styling lives in `css/styles.css`.
